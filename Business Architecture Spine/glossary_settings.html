A governed term deep-links to the workbench; the chip below is a live link when the term is governed, inert otherwise.

How the glossary is linked. The governed terms come from the term export baked into this source (the file you provide from the Glossary Workbench). Each term resolves to its exact workbench deep-link automatically — the Base URL above is simply which glossary those links point at, so to repoint the pack at a different glossary, change the Base URL. The Link template is only a fallback for a source that has no baked term list. Only terms that exist in the export will link; anything else stays inert (no broken links).
