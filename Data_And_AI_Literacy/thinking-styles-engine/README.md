# Thinking Styles Engine

Modelware Thinking Styles assessment (Gregorc model) — part of the Data & AI Talent Strategy suite.

Two axes — Perception (Concrete / Abstract) × Ordering (Sequential / Random) — give four styles:
Concrete Sequential, Abstract Sequential, Abstract Random, Concrete Random. Fifteen word-groups,
mark two words each (30 marks × 4 points = 120, max 60 per style). Bands: dominant >40, less-likely <30, weak <20.

Self-contained, client-side scored. Assessment → individual report (radar, bands, style descriptions,
learning 2×2, career context) → JSON export / print / optional save to the private repo. Includes a
team/cohort dashboard (overlay radar, style composition, blind-spot flags, filters, org roll-up).

The authoritative scoring key and the migrated 523-response norming set live in the private
`modelware_app_storage` repo under `Data_And_AI_Literacy/thinking-styles-engine/`.

Version is in the `<meta name="version">` tag and shown as a badge (with build timestamp).
