# Strengths Engine

A forced-choice strengths assessment. 170 paired statements rank all 34 themes
across the four domains (Executing, Influencing, Relationship Building,
Strategic Thinking). Single self-contained page; scoring runs in the browser.

- **Version:** 1.0.0
- **Scorer:** pairwise Bradley–Terry (MM). A Thurstonian IRT re-fit is planned
  once enough real responses are collected.
- **Design:** balanced block pairing, offsets ±{1,2,3,5,8} mod 34 — each theme
  appears in exactly 10 pairs.
- **Output:** a profile JSON (ranking, domain mix, raw choices) for export.
- **IP:** theme names and definitions align to the CliftonStrengths framework;
  every statement item is original to Modelware Systems.
