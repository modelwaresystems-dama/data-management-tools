Governance — the gate every AI opportunity passes before build

AI Use-Case Gate

Following the Business-Centered framework, an AI use case is valid only when it traces to a strategic outcome, an accountable decision, governed data, applicable controls, and a measurable benefit. Each use case is checked against four prerequisite gates and the ten-link traceability chain, scored across eight prioritisation dimensions, and placed in a portfolio bucket.

Portfolio — value vs readiness

Each use case placed by business value and delivery readiness. Sprint the top-right; prepare enablers for high-value / low-readiness; hold the bottom-left.
